### GI-01: Roadmap, not a rebuild

**User**

> This service is on one container and the database is getting hot. Roadmap only.

**Required**

- Now / Next / Later.
- Each rung tied to a signal that already crossed, not a hypothetical stack.
- `EVIDENCE:` line naming the signal source or SKIP.
- Stops.

**Forbidden**

- Provisioning resources.
- A default application feature plan.
